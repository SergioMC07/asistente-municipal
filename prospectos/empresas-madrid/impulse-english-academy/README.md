## Antes de llamar

1. **Prueba del mensaje:** escríbeles como cliente fuera de horario (por su WhatsApp, su formulario o su email) y apunta cuándo contestan.
2. Abre su demo y pregúntale «¿Cuánto cuesta para adultos?».
3. Para enseñar «Lo que no supo responder», pregúntale «¿Preparáis el examen B2 First de Cambridge?».
4. Practica con el prompt de [../../empresas/PROMPT-VENTA.md](../../empresas/PROMPT-VENTA.md) pegando este bloque en «NEGOCIO AL QUE LLAMO»:
